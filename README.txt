SUPER CLASH ARENA — Browser Platform Fighter

FILES
- index.html
- style.css
- game.js

HOW TO PLAY LOCALLY
1. Put all three files in the same folder.
2. Open index.html in a modern browser.
3. On iPhone/iPad, hosting it on a static host is recommended because iOS Files preview can restrict JavaScript.

HOSTING
Upload the whole folder to any static web host, including GitHub Pages or Netlify.

CONTROLS
A/D or arrows: move
W / Up / Space: jump
S / Down: crouch / fast-fall / platform drop
J: attack
K: special
L: shield / dodge
I: grab
Esc: pause

FEATURES
- 4 original fighters
- 3 stages
- stocks + percentage damage
- scaling knockback
- directional grounded attacks
- directional aerial attacks
- unique special styles
- shields + shield break
- rolls / air dodge
- grabs
- double jumps / fast fall
- pass-through platforms
- blast zones / respawns / invincibility
- CPU opponent
- keyboard, touch and basic gamepad-ready architecture
- responsive mobile UI

This build uses original vector-style characters and original names rather than copyrighted SSF2/Nintendo assets.
